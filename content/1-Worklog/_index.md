This page records the chronological progress of my 12-week internship journey in the **AWS Workforce Bootcamp – First Cloud AI Journey** program at Amazon Web Services Vietnam Co., Ltd. The journey spans from mastering foundational AWS cloud services, hands-on networking, security, and databases, to developing the web application interface and final product deployment.

The detailed weekly roadmap is listed below:

**Week 1:** [HCM Portal registration, AWS Credits activation, AWS Budgets setup, and basic AWS services](1.1-week1/)

**Week 2:** [AWS IAM, Shared Responsibility Model, and Account Management](1.2-week2/)

**Week 3:** [Amazon VPC hands-on, basic networking configuration, and FCAJ Community Day attendance](1.3-week3/)

**Week 4:** [Hybrid Networking, Route 53, VPC Peering, and AWS Transit Gateway](1.4-week4/)

**Week 5:** [Amazon EC2, AWS Backup, Amazon S3, CloudFront, and Bucket Replication](1.5-week5/)

**Week 6:** [Amazon RDS, AWS Storage Services, and website UI design setup](1.6-week6/)

**Week 7:** [AWS Security Hub, Cognito, KMS, and website UI completion](1.7-week7/)

**Week 8:** [Database Migration, Amazon Aurora, and Workshop/Lab content finalization](1.8-week8/)

**Week 9:** [AWS HCMC office training on RDS/Aurora/DMS and Frontend development](1.9-week9/)

**Week 10:** [Advanced IAM, CloudTrail, Athena, API integration, and website optimization](1.10-week10/)

**Week 11:** [Feature completion, end-to-end testing, and Frontend/Backend data synchronization](1.11-week11/)

**Week 12:** [Website deployment to AWS, internship report finalization, and program summary](1.12-week12/)
